Реализация AI-агента на чистом Python без использования фреймворков (LangChain, LangGraph и др.). Агент функционирует в автономном цикле **«Мысль – Действие – Наблюдение» (ReAct)**, отвечает на вопросы по внутренним документам компании и проводит необходимые математические расчёты.

## 🛠️ Архитектура и Инструменты

Агент принимает текстовые вопросы пользователя и последовательно выполняет шаги с помощью следующих встроенных инструментов:

1. **`calculator(expression)`** — безопасный калькулятор на основе модуля `ast` (без `eval`), защищающий систему от RCE-уязвимостей.

2. **`text_search(query)`** — поисковый модуль, который осуществляет разбиение текстовых файлов (`.txt`) из каталога `docs/` на абзацы и производит токенное ранжирование.

3. **JSONL Logging (`agent_log.jsonl`)** — система логирования, фиксирующая каждую итерацию (время, задержку LLM, токены, признак успеха инструмента `tool_ok`).

## 📁 Структура проекта

```
react_agent/
├── docs/                     # Текстовые документы компании (HR, правила, лимиты)
│   ├── hr_policy.txt
│   └── perks_policy.txt
├── agent.py                  # Основной модуль: ReAct-цикл, системный промпт, парсер
├── tools.py                  # Модуль инструментов (безопасный калькулятор и поиск)
├── tests.py                  # Автоматический прогон тестов и вычисление метрик
├── agent_log.jsonl           # Журнал работы агента (генерируется автоматически)
└── README.md                 # Документация проекта

```

## 🚀 Быстрый запуск

### 1. Клонирование и настройка окружения

```
# Перейдите в папку проекта
cd react_agent

# Создайте и активируйте виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate  # Для Windows: .venv\Scripts\activate

# Установите зависимости
pip install openai pandas

```

### 2. Настройка ключа API (Groq)

Получите API-ключ в [Console Groq Cloud](https://console.groq.com/keys) и экспортируйте его в переменные окружения:

```
export GROQ_API_KEY="ваш_ключ_groq"
export LLM_BASE_URL="https://api.groq.com/openai/v1"
export LLM_MODEL="qwen/qwen3.8-27b"

```

*(Альтернативно можно использовать локальную `Ollama`: `LLM_BASE_URL="http://localhost:11434/v1"`).*

### 3. Запуск тестов и сбор метрик

Для запуска 5 базовых тестовых сценариев и автоматического вычисления метрик выполните:

```
rm -f agent_log.jsonl && python tests.py

```

## 🧪 Запуск сценариев «поломки» (Раздел 10.4)

Для проверки устойчивости агента и отслеживания его корректного поведения при сбоях:

1. **Запрос отсутствующего инструмента (Погода):**

   ```
   python -c "from agent import run_agent; print(run_agent('Какая сейчас погода в Бишкеке?'))"
   
   ```

2. **Отсутствие данных в документах (Зарплата):**

   ```
   python -c "from agent import run_agent; print(run_agent('Какая зарплата у генерального директора?'))"
   
   ```
